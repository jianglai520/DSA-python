## 1. 为什么它们看起来这么像？

很多学习者在同时接触**动态规划（DP）和马尔可夫链（Markov Chain）**时，都会产生一种强烈的既视感：

> “这不就是同一套东西吗？”

这种感觉是**完全正确**的。因为它们共享一个最核心的数学性质——**无后效性（Markov Property）**。

| 概念 | 马尔可夫链的说法 | 动态规划的说法 |
| :--- | :--- | :--- |
| **核心性质** | 下一时刻的状态**只依赖于当前状态**，与更早的历史无关。 | 当前状态的最优值**只依赖于前面有限个状态**（如 `dp[i-1]`、`dp[i-2]`）。 |
| **历史处理** | 过去的历史被“压缩”在当前状态中。 | 过去的决策被“压缩”在 `dp[i]` 的数值中。 |
| **举例** | 明天是否下雨，只取决于今天的天气。 | 偷到第 `i` 间房的最大金额，只取决于前 1~2 间的最优值。 |

## 2. 核心共性：无后效性（马尔可夫性质）

### 形式化定义

**马尔可夫性质**（离散时间）：
P(X_{n+1} = x | X_1 = x_1, X_2 = x_2, ..., X_n = x_n) = P(X_{n+1} = x | X_n = x_n)

text

**动态规划的无后效性**：
dp[i] = f(dp[i-1], dp[i-2], ..., dp[i-k])

text

即：`dp[i]` 的计算**只依赖于之前有限个状态**，而无需追溯到整个历史序列。

### 在打家劫舍中的体现

当我们计算 `dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])` 时：

- 我们**不需要知道**前 `i-3` 间房具体偷了哪几家。
- 我们**只需要知道**两个数字：`dp[i-1]` 和 `dp[i-2]`。
- 更早的历史已经被“压缩”进这两个值里了。

**这就是“状态”的力量——用有限的信息表示无限的历史。**

## 3. 动态规划是“确定性的马尔可夫决策过程”

如果你接触过**马尔可夫决策过程（Markov Decision Process, MDP）**，你会发现动态规划就是它的**确定性特例**。

| MDP 概念 | 对应到动态规划 |
| :--- | :--- |
| **状态（State）** | `dp[i]`、`dp[i][j]` 等状态变量。 |
| **动作（Action）** | “偷”或“不偷”、“选”或“不选”。 |
| **状态转移概率** | **确定性的**：转移是 100% 确定的（没有随机性）。 |
| **奖励（Reward）** | 偷到的金额 `nums[i]`、背包的价值 `v[i]`。 |
| **策略（Policy）** | 每个状态下选择哪个动作。 |
| **目标** | 最大化长期累积奖励（最优策略）。 |

### 一个完整的对应表（以打家劫舍为例）

| 层级 | 马尔可夫决策过程 | 打家劫舍（DP） |
| :--- | :--- | :--- |
| 状态 | 当前在第 `i` 间房。 | `dp[i]` 表示前 `i` 间的最优值。 |
| 动作 | 偷 / 不偷。 | `max(dp[i-1], dp[i-2] + nums[i-1])`。 |
| 转移 | 偷 → 跳到 `i+2`；不偷 → 跳到 `i+1`。 | 同上，由方程决定。 |
| 奖励 | 偷则获得 `nums[i]`。 | 同左。 |
| 最优方程 | **Bellman 方程**：<br>`V(s) = max_a [ R(s,a) + V(s') ]` | **状态转移方程**：<br>`dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])` |

> **结论**：动态规划 = 在确定性环境下的马尔可夫决策过程，用 Bellman 方程求解最优策略。

## 4. 核心区别：优化 vs 概率

虽然它们结构相似，但**研究目的**完全不同：

| 维度 | **动态规划（DP）** | **马尔可夫链（MC）** |
| :--- | :--- | :--- |
| **研究目标** | **最优化**：求最大/最小值。 | **随机过程**：求概率分布、期望、稳态。 |
| **转移性质** | 确定性转移（选择最优路径）。 | 概率转移（按转移矩阵随机跳转）。 |
| **核心方程** | **Bellman 最优性方程**：<br>`dp[i] = max/min( dp[i-1] + cost )` | **Chapman-Kolmogorov 方程**：<br>`P(X_n) = P(X_{n-1}) · P` |
| **经典问题** | 背包、打家劫舍、编辑距离、LIS。 | 股市预测、PageRank、语音识别、排队论。 |
| **输出结果** | 一个最优值（或最优策略）。 | 一个概率分布（或稳态分布）。 |

### 一句话总结

> **马尔可夫链是“描述世界如何随机运转”，动态规划是“在这个世界中如何做最优选择”。**

## 5. 阶数概念：一阶、二阶与高阶

### 什么是“阶”？

- **一阶马尔可夫性**：`dp[i]` 只依赖 `dp[i-1]`。
- **二阶马尔可夫性**：`dp[i]` 依赖 `dp[i-1]` 和 `dp[i-2]`。
- **k 阶马尔可夫性**：`dp[i]` 依赖前 `k` 个状态。

### 常见 DP 的“阶数”分类

| 问题 | 状态转移方程 | 阶数 | 空间复杂度 |
| :--- | :--- | :--- | :--- |
| 最大子数组和 | `dp[i] = max(nums[i], dp[i-1] + nums[i])` | 一阶 | O(1)（滚动） |
| 爬楼梯 / 斐波那契 | `dp[i] = dp[i-1] + dp[i-2]` | **二阶** | O(1)（两个变量） |
| 打家劫舍 | `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` | **二阶** | O(1)（两个变量） |
| 最长递增子序列（LIS） | `dp[i] = max(dp[j] + 1)` for `j < i` | **非马尔可夫**（依赖所有历史） | O(n)（无法压缩） |

### 如何判断能否做空间优化？

**法则**：
- 如果 `dp[i]` 只依赖常数个前驱状态 → **可以压缩到 O(1)**。
- 如果 `dp[i]` 依赖所有 `j < i` 的状态 → **必须保留全部 O(n)**。

## 6. 这个视角对刷题的启发

掌握了“DP ≈ 马尔可夫决策过程”这个视角后，你在刷题时可以问自己三个问题：

### 问题 1：我的状态定义是否具有“无后效性”？
- 如果 `dp[i]` 的计算需要知道“具体偷了哪些房子”，那就说明状态定义不够好。
- 好的状态定义应该把历史“压缩”成有限的几个数字。

### 问题 2：这是几阶马尔可夫？
- 一阶 → 一个变量滚动（`prev`）。
- 二阶 → 两个变量滚动（`prev1`, `prev2`）。
- 高阶或全历史 → 考虑二维 DP 或优化数据结构（如树状数组）。

### 问题 3：如果转移是随机的，该怎么变？
- 面试中的 DP 都是确定性的。
- 如果遇到概率 DP（如 LeetCode 808 汤米服务），方程变为 `dp[i] = sum(p * dp[next])`，本质上是求解**马尔可夫链的期望**。

```text
                    随机性
                       |
                       v
              ┌─────────────────┐
              │   马尔可夫链     │  ← 研究“概率如何演化”
              │   (Markov Chain) │
              └────────┬────────┘
                       |
                       | 加入“决策”和“奖励”
                       v
              ┌─────────────────┐
              │ 马尔可夫决策过程 │  ← 研究“如何做最优决策”
              │      (MDP)      │
              └────────┬────────┘
                       |
                       | 去掉随机性（概率 = 1 或 0）
                       v
              ┌─────────────────┐
              │   动态规划 (DP)  │  ← 确定性环境下的最优决策
              └─────────────────┘
```
