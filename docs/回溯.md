**什么是回溯算法？**

是一种通过穷举所有可能情况来找到所有解的算法。它采用深度优先搜索策略（DFS），在搜索过程中不断地尝试可能的解，当发现当前选择不满足条件时，就撤销上一步的选择（回溯），尝试其他可能性。

**大白话：**

回溯就像是在走迷宫：

每到一个岔路口，先选一条路走

如果走到死胡同，就原路返回到上一个岔路口

换另外一条路继续走

直到走完所有可能的路

**回溯算法的万能模板**

```
def backtrack(路径, 选择列表):
    # 1. 结束条件：找到了一个解
    if 满足结束条件:
        结果集.append(路径)
        return
    
    # 2. 遍历所有选择
    for 选择 in 选择列表:
        # 3. 剪枝（可选）：排除不合法选择
        if 选择不合法:
            continue
        
        # 4. 做选择
        路径.append(选择)
        
        # 5. 递归：进入下一层决策
        backtrack(路径, 新的选择列表)
        
        # 6. 撤销选择（回溯的核心！）
        路径.pop()
