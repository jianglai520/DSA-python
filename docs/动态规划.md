## 1. 什么是动态规划？

**动态规划（Dynamic Programming，简称 DP）** 是一种通过把原问题分解为相对简单的子问题，并**保存子问题的解**，从而**避免重复计算**，解决复杂问题的算法思想。

### 一句话大白话定义
> **动态规划 = 用空间换时间 + 记住之前算过的答案 + 从小问题推导出大问题。**

---

## 2. 动态规划的核心思想

动态规划通常用于解决具有以下两个**核心特性**的问题：

### （1）最优子结构（Optimal Substructure）
- 一个问题的最优解，可以由它的子问题的最优解组合而成。
- **举例**：爬楼梯问题中，到第 `i` 级的最优解，依赖于到第 `i-1` 级和第 `i-2` 级的解。

### （2）重叠子问题（Overlapping Subproblems）
- 在求解过程中，同一个子问题会被反复计算多次。
- **举例**：计算斐波那契数列时，`f(5)` 需要计算 `f(4)` 和 `f(3)`，而 `f(4)` 又需要计算 `f(3)`，导致 `f(3)` 被重复计算。

---

## 3. 动态规划 vs 递归（核心区别）

| 对比维度 | **递归（自顶向下）** | **动态规划（自底向上）** |
| :--- | :--- | :--- |
| **方向** | 从大问题开始，逐层拆解到最小问题。 | 从最小问题开始，逐步推导到大问题。 |
| **实现方式** | 函数调用自身（递归调用）。 | 使用循环（For/While）迭代计算。 |
| **重复计算** | 存在大量重复计算（指数级），效率极低。 | 每个子问题只计算一次，效率极高。 |
| **空间开销** | 递归调用栈可能溢出（Stack Overflow）。 | 无递归栈风险，可进一步优化空间（如状态压缩）。 |
| **思维模式** | 符合人类直觉，容易推导状态转移方程。 | 需要思考递推顺序和边界条件。 |

### 代码对比：爬楼梯（斐波那契数列）

**❌ 纯递归（自顶向下）- 低效**
```python
def fib(n):
    if n <= 2:
        return n
    return fib(n-1) + fib(n-2)  # 大量重复计算
```

**✅动态规划(自底向上）- 高效**

```python
def fib(n):
    if n <= 2:
        return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):   # 从小到大，自底向上
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
